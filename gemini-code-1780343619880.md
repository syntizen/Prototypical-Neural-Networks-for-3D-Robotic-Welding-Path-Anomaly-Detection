This repository implements an end-to-end deep metric learning framework utilizing **Prototypical Networks (Few-Shot Learning)** to detect structural wear and operational degradation in industrial $6\text{-DOF}$ robotic welding arms. Structured like a chronological Google Colab notebook, this document follows the exact pipeline sequence—from forward kinematics simulation and dataset generation to deep metric learning optimization and final 3D workspace analysis.

---

## 📌 Core Architecture & Logic

In precision automated manufacturing, micro-degradations in joints (e.g., mechanical backlash, motor encoder offset, or joint play) lead to sub-millimeter path deviations that compromise weld seam integrity. 

This framework implements a temporal $1\text{-D}$ **Convolutional Neural Network (1D-CNN)** feature encoder optimized via **episodic few-shot constraints**. The network projects complex $3\text{-D}$ end-effector coordinate trajectories into a highly discriminative $128$-dimensional embedding space. Within this learned space, normal operational behaviors gather into tight cluster regions around their respective task prototypes, while mechanical wear and joint failures fall completely outside normal bounds, enabling robust distance-based anomaly classification.
